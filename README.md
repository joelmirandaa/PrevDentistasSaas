# Preve Dentista - Sistema web de gestão para uma clínica odontológica
O trabalho partiu do contato com uma clínica real, utilizada como referência para a coleta de dados, o levantamento de requisitos e a definição das funcionalidades.
A equipe participou de todas as etapas do projeto, desde a compreensão das necessidades da clínica até a implementação de um sistema completo e funcional, com agendamento de consultas, 
controle de pagamentos e armazenamento das informações em banco de dados.

Objetivo
Desenvolver uma aplicação para apoiar a rotina de uma clínica odontológica.

# Funcionalidades
- Agendamento de consultas.
- Alteração de consultas agendadas.
- Registro e controle de pagamentos.
- Registro das formas de pagamento, incluindo débito e crédito.
- Armazenamento e consulta de informações em banco de dados.

# Tecnologias utilizadas
| Tecnologia | Aplicação no projeto |
| PHP        | Implementação das regras de negócio e comunicação com o banco de dados. 
| CSS        | Estilização das páginas e organização visual da interface. 
| JavaScript | Interações e comportamentos da interface. 
| MariaDB    | Armazenamento e gerenciamento dos dados. 
| Docker     | Organização do ambiente de execução em contêineres. 

Processo de desenvolvimento
O projeto foi construído a partir das necessidades identificadas junto à clínica. O trabalho envolveu:
1. Contato com a clínica e compreensão de sua rotina.
2. Coleta de dados para identificar necessidades e processos.
3. Levantamento e definição dos requisitos do sistema.
4. Planejamento da aplicação e estruturação do banco de dados.
5. Desenvolvimento das interfaces e das funcionalidades.
6. Integração entre a aplicação e o banco de dados.
7. Verificação do funcionamento e realização de ajustes.

Contexto acadêmico
A Preve Dentista foi desenvolvida como projeto acadêmico baseado em uma clínica real.
Essa aproximação permitiu trabalhar com necessidades concretas e compreender como transformar os processos de
uma organização em requisitos e funcionalidades de software.
